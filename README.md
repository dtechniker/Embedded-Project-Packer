# Embedded-Project-Packer
A lightweight CLI tool that packs multi-file C++/ESP32 projects into a single structured text file optimized for LLM context windows (Gemini, Claude, ChatGPT).


<img src="Embedded Project Packer (by DTech).jpg" alt="Interface" width="800">

DE
## ✨ Key Features

* **🔒 100% Client-Side & Privacy First:** Keine Server-Übertragung. Alle Dateien werden lokal im Browser verarbeitet.
* **🎯 Token-Optimiert:** Verwendet schlanke Markdown-Header (`## Dateiname`) ohne unnötigen Overhead, um maximale Kontextkapazität in LLMs zu sparen.
* **📂 Drag & Drop Support:** Unterstützt `.ino`, `.cpp`, `.h`, `.c`, `.hpp` und `.txt` Dateien.
* **🌐 Zero-Installation:** Läuft direkt im Browser oder gehostet über GitHub Pages – keine Installation, kein Node.js/Python nötig.
* **📊 Metadata-Header:** Ergänzt jede Datei im Paket automatisch um kompakte Metadaten (Dateinummer, Name, Byte-Größe).

## ✨ Key Features

* **🔒 100% Client-Side & Privacy First:** No server transfer. All files are processed locally in the browser.
* **🎯 Token-Optimized:** Uses lean Markdown headers (`## filename`) without unnecessary overhead to maximize context capacity in LLMs.
* **📂 Drag & Drop Support:** Supports `.ino`, `.cpp`, `.h`, `.c`, `.hpp`, and `.txt` files.
* **🌐 Zero-Installation:** Runs directly in the browser or hosted on GitHub Pages – no installation, no Node.js/Python required.
* **📊 Metadata Headers:** Automatically adds compact metadata (file number, name, byte size) to each file in the package.
